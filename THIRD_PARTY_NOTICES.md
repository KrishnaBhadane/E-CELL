# Component credits

## Skiper UI 39

The user-supplied Crowd Canvas is adapted in `src/components/ui/skiper39.tsx`.
Creator: Gurvinder Singh / https://skiper-ui.com/.
Crowd illustration: https://www.openpeeps.com/; original crowd inspiration:
https://codepen.io/zadvorsky/pen/xxwbBQV.
The supplied free-use terms require attribution; links are included in the relevant page footers.
The canvas uses a capped native animation loop in place of per-person GSAP timelines.

## User-supplied components

`src/components/ui/tiger-tear-reveal.tsx` and `nav-header.tsx` are adapted from the
components supplied in this conversation. Changes include brand colors and typography,
a persistent-header offset, keyboard links, typed navigation state, reduced-motion
controls, and pausing the tiger animation offscreen or in background tabs.

## Magic UI — Border Beam, via 21st.dev

Catalog: https://21st.dev/@dillionverma/components/border-beam
Source: https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/border-beam.tsx

`src/components/BorderBeam.tsx` and its CSS adapt the masked border, gradient, and
offset-path animation into a narrow header rail. The animation uses CSS instead of Motion.
